# 이재모피자 데이터 프로젝트 · 학습 폴더

부산 로컬 음식점 이재모피자를 사례로, 리뷰 반응과 관광 데이터를 살펴보는 6주 학습 폴더입니다.

## 폴더 안내

| 경로 | 용도 |
|---|---|
| `CLAUDE.md` | 프로젝트 목표와 근거 확인 규칙 |
| `keyword-map.md` | 부산·이재모피자 관련 조사 키워드와 근거 |
| `SOURCE.md` | 현재 제공된 CSV의 출처와 한계 |
| `inputs/` | 현재 제공된 부산 축제·관광 데이터 CSV |
| `prompts/` | 키워드 맵 및 조사 작업용 프롬프트 |
| `examples/` | 근거를 구분하는 Before/After 예시 |
| `research/` | 주제 후보, 조사 노트와 노트 템플릿 |

## 시작 순서

1. `CLAUDE.md`의 개인화할 부분을 본인 정보로 채웁니다.
2. `SOURCE.md`에서 데이터의 기준 기간과 한계를 확인합니다.
3. `keyword-map.md`와 조사 노트를 보완합니다.

기존 주제 후보 메모는 [research/2026-11-12-주제후보.md](./research/2026-11-12-주제후보.md)에 보존했습니다.

## 데이터 현황

현재 `inputs/`에는 축제 CSV 1개와 한국관광 데이터랩 CSV 5개가 있습니다. 리뷰, 매장별 매출, 점포별 상권 데이터는 포함되어 있지 않습니다. 파일별 행 수와 출처는 [SOURCE.md](./SOURCE.md)를 확인하세요.

프로젝트 후보에 적힌 기사 내용은 조사 시작점입니다. 원문과 수치가 확인되기 전까지 확정된 사실처럼 인용하지 않습니다.
